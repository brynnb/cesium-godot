# Cesium for Unreal to Cesium for Godot porting map

This ledger tracks the relationship between the official Cesium for Unreal
runtime and this Godot GDExtension. It is intentionally explicit so upstream
changes can be reviewed without relying on contributor memory.

## Reference baseline

- Repository: `https://github.com/CesiumGS/cesium-unreal.git`
- Release: `v2.29.0`
- Commit: `71006dd`
- Cesium Native: `v0.63.0` at
  `b4137763914820b01a42b52ee886a55b036cd6ac` (the release's exact submodule)
- Godot: `4.6.3` minimum and tested runtime
- Upstream reference: [Cesium for Unreal v2.29.0](https://github.com/CesiumGS/cesium-unreal/tree/v2.29.0)
- Last full map review: 2026-08-12

Cesium for Unreal and this repository are Apache-2.0 licensed. Preserve source
attribution when copying code or substantial logic. This map records conceptual
counterparts; it does not imply that Unreal-specific code should be copied
literally.

## Status meanings

- **Ported**: behavior is intended to match upstream closely.
- **Adapted**: upstream semantics are implemented using a deliberately
  Godot-native API or ownership model.
- **Partial**: a counterpart exists, but important behavior or tests remain.
- **Skipped**: intentionally not planned; the reason must be recorded.
- **Not started**: useful or required work with no adequate counterpart yet.

## Update procedure

When reviewing a newer Cesium for Unreal release:

1. Record the new release and commit without deleting the old review history.
2. Diff each mapped upstream file against the last reviewed baseline.
3. Classify each upstream change as engine-neutral, Unreal-specific, or already
   supplied by the pinned Cesium Native version.
4. Port engine-neutral bug fixes and behavior changes with attribution.
5. Translate Unreal-specific changes only when the same user-facing behavior is
   appropriate for Godot.
6. Run the counterpart's tests and the Vanguard benchmark before changing its
   status or reviewed version.
7. Document intentional differences here so a later update does not mistakenly
   erase them.
